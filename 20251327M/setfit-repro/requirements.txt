# Read this before changing anything here.

# The organisers ran their notebook on the setfit ~1.0 / transformers ~4.39
# generation, and the first version of this file pinned exactly that. It does
# not install on Python 3.12, and it is not safe to pair with torch 2.11 --
# transformers 4.39 predates API changes that later torch releases made.
#
# So the reproduction runs on current releases instead, and the version drift
# is handled the only honest way available: it is *recorded*. Every results
# file carries the exact versions under "versions", and the report should name
# library drift as a threat to validity rather than pretend it is absent.
#
# The one behavioural difference between the two generations that is known to
# matter is whether the encoder's configured max_seq_length is applied.
# src/runner.py sets it explicitly to 384, so that difference is controlled
# rather than inherited.
#
# torch is deliberately absent: RunPod's PyTorch templates ship a build already
# matched to the pod's CUDA. Installing another one can leave you with a torch
# that cannot see the GPU. Check it first -- see README.md.
